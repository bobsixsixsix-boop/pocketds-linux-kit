# Pocket DS 下屏 UI 设计约束

本文件约束 Plasma Panel 与 GTK 触控键盘。它记录可复用规则，不替代真机触摸、
逐像素截图或可访问性验收。

## 使用场景与几何

- 下屏物理横向分辨率是 1024×768，当前 1.25 scale 下 KWin 逻辑区是
  `(283,720) 819×614`。
- Panel 的绘制边界以 `Plasmoid.screenGeometry` 为准。
- 键盘只在显示时读取新鲜的 `%t/pocketds-gpu-status.json`，要求完整、启用且不过期
  的 DSI-2 逻辑 `x/y/width/height`。缺失或异常时才回退已验证的
  `(283,720) 819×614`，不得再使用旧的 820×615 常量。
- 不从物理像素反推触摸窗口几何，也不假设 fractional scale 永远不变。

## 视觉语言

这是高频使用的掌机操作面，不是展示页。默认是低眩光、高密度、低动效；信息依靠
字号、字重、间距和细分隔线建立层级，不靠卡片堆叠。

| 角色 | 值 | 用途 |
|---|---|---|
| page | `#0b111b` | 下屏完整背景 |
| surface | `#172130` | 一层功能分组与主键 |
| pressed | `#223149` | 普通按压或次级操作 |
| border | `#334258` | 一层边界与键边界 |
| divider | `#29374a` | 同一 surface 内的数据分隔 |
| text | `#eef4ff` | 主信息 |
| muted | `#a7b6ca` | 辅助信息，不得低于日用可读对比度 |
| accent | `#69dff5` | 当前选择、进度和主操作 |
| success | `#5ee3b8` | 真实成功或充电状态 |
| danger | `#ff718b` | 真实失败、低电或正在录音等需注意状态 |

圆角只有三档：键和 profile 10-12 px，surface 14 px，小型 meter/track 为自身高度
的一半。状态色只表达语义；收起、返回等可逆动作保持中性。

## Panel 信息架构

1. 顶部栏只保留身份、显示模式、电池、四个全局动作和时间。四个动作必须同时显示
   图标与“全屏、按键、恢复、桌面”文字，不能把 tooltip 当作触屏标签。
2. CPU、GPU、整机功耗、网络与 Codex 配额属于一条遥测 surface；各列用 1 px
   分隔，不再各自套一张同权卡片。风扇读数留在紧接其控制器的大卡内，避免重复
   占用顶部五列并压缩字号。
3. 左侧是风扇与性能调度，右侧是亮度、音量和键盘入口。安全温控说明必须可见。
4. 键盘是右侧唯一的主按钮，文案为“键盘与语音输入”，明确它同时承载两条路径。
5. 无数据必须显示未知或等待状态，不得用 0 冒充有效采样。
6. 第一份有效状态到达前显示“等待遥测”；最后一次有效状态超过 6.5 秒后显示
   “遥测中断”，读数回到未知，并禁用风扇、性能、亮度、音量等状态修改控件。
   全屏、按键说明、桌面恢复/折叠和键盘入口不依赖遥测，仍可用于逃生。

Panel 触点基线：顶部工具按钮至少 48×48 逻辑像素，profile 52 px 高，主按钮
64 px 高，slider 触控区 42 px 高、track 10 px、handle 32 px。

## 键盘布局

- F1-F12 是紧凑功能条，不与高频输入键等高。
- 主体保持数字、QWERTY、Home、Shift/Z 行和底部工具行；字母/数字仍是最大触点。
- 底排必须直接提供 `.` 和 `/`，同时保留中英切换、语音、空格、回车和收起。
- 上档、退格和收起使用文字，不依赖可能缺字或风格不一致的 Unicode 图标。
- 普通页与符号页都必须提供“退格”，按住时沿用同一套有界连续删除行为；符号页
  不得让用户为了纠错先切回普通页。
- 语音空闲时不应比普通输入更抢眼；只有录音中或失败时使用 danger 状态。
- 键盘重建、按键注入、手动显示和自动显示的既有行为不得因视觉调整改变。

## 交互与动效

- 键盘属于每天数百次的高频操作。按键反馈立即改变 surface/border，不播放开合、
  位移、弹跳或逐键动画。
- Panel profile 与主按钮只允许 100-110 ms 的轻微按压缩放，作用是确认触摸已接收。
- 两秒一次的遥测 meter 不做 width tween，避免持续产生无意义的动效和视觉拖尾。
- 对话框继续使用 KDE 原生 modal 行为；恢复桌面等危险路径必须保留确认和失败状态。
- hover tooltip 不能成为触屏唯一说明，关键名称必须直接可见或在快捷说明页可达。

## 有界验收

每个 UI 批次只做一次完整截图批检，集中修复后最多一次确认。必须覆盖：

- 819×614 四边覆盖和无溢出；
- 中文长文案、未知/过期/失败/禁用状态；
- Panel 收起/重进、全屏、恢复对话框与键盘入口；
- 键盘普通、Shift、符号、语音忙碌和隐藏状态；
- 真实手指触控、上屏焦点保持、Chromium/Konsole 自动显示以及 XWayland 重连；
- 无新增 Plasma/QML/GTK 警告、服务退出或 telemetry cadence 退化。
