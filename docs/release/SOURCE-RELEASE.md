# 首次源码公开准备

首发范围是 Pocket DS Linux Kit 的源码预览。发布平台待定，当前不创建公开仓库、不打发行
标签、不上传资产或刷机包。独立准备分支保留在本地，原仓库继续私有；日用设备沿用已有安装。

## 已完成的准备

- 面向新读者的 README、支持范围、安装恢复、贡献和隐私说明。
- 语音改用用户自备的 OpenAI 兼容转写 API；无预置服务、密钥或设备 ID，不恢复个人预设。
  未配置不阻断普通键盘，日用设备的原配置不参与开源整理。
- 维护者已选择原创代码 GPL-3.0-or-later，顶层 LICENSE 和 NOTICE 明确授权与第三方例外。
- 第三方来源和许可范围汇总，ALSA、Phosphor 和 Switchdeck 的完整许可补齐；
  Phosphor 与 Switchdeck 记录固定比对基线，gamescope 从固定版本重新导入。
  未知的原始复制版本明确保留为未知，不虚构历史来源。
- 无素材清单支持 Git 克隆不保存空目录的实际行为。
- 从干净提交导出的源码预览工具，不携带原 Git 对象、ignored 文件或外部工作缓存。

## 发布前仍需明确

| 项目 | 当前要求 |
|---|---|
| 第三方产物 | 源码保留适用许可与固定来源记录；模型、运行时、壁纸及系统镜像不在本次分发范围，后续打包另核对 |
| 公开身份与平台 | 确定仓库地址、公开提交身份和私密安全报告入口 |
| 最终产物 | 对确切源码提交重新导出、扫描、检查清单和归档摘要，再审阅发布 |

最新触摸输入修复及用户“看起来修好了”的反馈已同步入候选。
独立发现的手柄测试鼠标按钮释放问题已提供 [源码候选](../../components/inputplumber/MOUSE-CLEAR.md)，
仍需二进制部署和实体操作验收；构建成功也不能将此项标成实机已修复。

首次源码公开保留已知硬件问题及未测范围，不假装已完成另一台设备的独立安装。
系统镜像、签名 RPM、完整 composition SBOM、救援和升级矩阵另按
[系统发行检查清单](../RELEASE-CHECKLIST.md) 推进。

## 生成本地预览

在源码根目录，确认所有候选变更已提交、工作树干净后运行：

```sh
python3 scripts/export-source-preview.py --output /absolute/path/to/new-preview
```

输出是 `source/`、确定性 `source.tar.gz`、文件与模式清单以及 `SHA256SUMS`。
工具只读取 HEAD 中的 tracked 文件，固定排除个人壁纸、个人 ASR 预设、预编译观察器和
`work/` 维护记录，生成精确空的 `components/assets/ASSETS.json`。源文件和构建脚本保留。
已经审阅并提交的 `docs/screenshots/` 实机截图及来源说明作为文档保留；这里的
`asset-free` 指不分发运行时壁纸等素材，不表示文档中没有图片。
导出后在 `source/` 中重新运行 [最小离线检查](../INSTALL.md#最小离线检查)。
观察器被刻意排除，安装前仍须按安装指南在兼容的 Linux 环境中构建。

冻结的内核重现配方 `tools/kernel-ab/reproducible-build/pinned-child.cfg` 保留历史构建路径。
这是已说明来源且受摘要约束的证据，不是当前用户路径或运行时依赖；不为脱敏改写已验证的
配方字节。旧私有语音服务的名称、地址、协议与账户操作细节不随当前源码预览分发；
用户按 [语音 API 配置](../VOICE-API.md) 提供自己的服务。旧 round-01 至 round-06 仅保留为
本地历史证据，不应继续用于发布。

导出字节检查已知 ASR、常见令牌、私钥和个人 macOS 路径模式，命中时只报文件和类别。
这种有限扫描不能证明任意编码或无特征的秘密不存在，最终文件仍需审阅。
扫描不识别图片像素中的文字；截图中的账户、网络名称、通知及背景内容需逐图人工复核，
同时检查图片文本元数据和第三方素材的分发范围。
`manifest.json` 始终标记为草稿，导出成功不是公开发布授权，也不替代许可证核对。

原私有历史曾包含个人访问码。不得直接将原仓库改为公开，也不得使用含历史的 bundle
作为公开源码包。首次公开仓库从经过审阅的干净预览建立新的历史，原私有记录独立保留。
