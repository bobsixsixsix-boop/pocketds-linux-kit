## 几何缓存加固

后续源码审计发现键盘几何读取器会直接 `Path.read_text()` telemetry
cache，因而会跟随 symlink，也没有所有者、权限、链接数、文件尺寸或
读取途中变化限制。这会让损坏/替换缓存进入窗口定位路径。

`screen_geometry.py` 现使用 `O_NOFOLLOW` 单 fd 读取，只接受当前用户所有、
0600 级别、单链接、非空且 ≤256 KiB 的 UTF-8 JSON 普通文件，并拒绝短读或
增长。任何违反均回退到已验证的 819×614，不会猜测几何。现场 cache
已只读确认为 mode 0600、uid 1000、单链接、1,369 字节普通文件。
新增用例覆盖公开权限、硬链接、符号链接、非 UTF-8 和超限文件；键盘
几何 5 项、焦点适配器 27 项及本地全量 `make test` PASS。此批仍只是
源码，soak 结束前不部署或重启键盘。
源码提交为本地 `85fde32`、设备 `28d278e`；设备端强化读取器只读解析
真实 cache 得到 `(283,720) 819×614`，目标测试与全量 `make test` PASS。

## 第二轮：错误状态与触屏自解释

本轮继续按 Impeccable 的 polish/craft-floor 和 Emil 的高频操作原则做窄幅修正，
没有重排现有信息架构。

| Before | After | Why |
|---|---|---|
| Panel 启动时把 CPU、温度、风扇、亮度和音量的占位值画成真实读数 | 首份状态前统一显示“等待遥测”和 `—`；超过 6.5 秒未收到有效状态后显示“遥测中断” | 0 是有效数值，不能拿它表达未知；用户必须能看见数据是否新鲜 |
| 遥测中断后旧读数仍可驱动风扇、性能、亮度和音量控件 | 读数失效并锁住所有依赖实时状态的硬件控制；全屏、按键说明、桌面恢复/折叠和键盘入口仍可用 | 失败时优先安全和逃生路径，避免基于旧状态盲写硬件 |
| 顶部四个全局动作只有图标，触屏用户只能猜或依赖 hover tooltip | 改为 60×48 的图标加中文标签：“全屏、按键、恢复、桌面” | 关键动作直接可见，tooltip 只补充说明而不是承担名称 |
| 符号页占满四行字符，没有退格键 | 最后一行保留全部十个符号，并给“退格”留出加宽触点；普通页和符号页复用相同长按连删实现 | 纠错不应要求切页，也不能因补动作丢失符号 |

本轮仍仅修改源码和离线契约。PDS-008 soak 结束前不部署、不 reload 图形组件，
真机渲染与触摸结论保持为待验收，不能由离线预览替代。
