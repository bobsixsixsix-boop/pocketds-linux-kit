# 键盘一键移上屏

> 公开版更新（2026-09-08）：语音已改为用户自备的 OpenAI 兼容 API。下文涉及旧语音后端的提交、测试数量和实机结果均为历史记录，不能作为新 API 的验收。旧服务身份与账户细节不公开。

键盘快捷栏在“终端”和“Alt+F4”之间增加“移上屏”。点击后，将当前归属 DSI-2 的应用窗口移到 DSI-1；键盘继续留在下屏，原有快捷键保留。

实现按一次窗口快照执行 KWin `sendClientToScreen`，包含最小化窗口、应用对话框和工具窗。不改变活动，不主动激活或取消最小化；窗口状态与恢复尺寸交由 KWin 保持。原生跨屏操作可能改变每屏虚拟桌面，因此先保存桌面归属，再按父子顺序恢复。它不监听未来窗口，也不改屏幕配置。

桌面、任务栏、输入法、键盘、触摸板、Panel 和 XWayland 视频桥辅助窗不参与移动。melonDS 的专用下屏窗口仍受双屏游戏布局规则约束；此按钮不卸载该规则。自定义平铺区域跨屏后的行为沿用 KWin。

请求在工作线程执行，单次只能有一个请求；等待期间按钮禁用，失败后可重试。临时脚本使用私有运行目录、随机名称和独占创建；加载、执行、卸载分别有超时，结束后清理。正常 D-Bus 回复只表示请求执行完毕，界面不据此声称所有窗口已成功移动。

验证：窗口迁移测试 17 项、键盘 adapter 208 项、可见性 13 项、几何 6 项与 UI 契约 20 项通过。最终源码在实机 Linux 上的完整 lint（Python、C++、JSON/XML、shell、桌面入口和凭据检查）通过；Mac 的全量 lint 受未改动的 Linux C++ `stat.st_mtim` 接口限制。

`b4061a1` 已部署并实机验收：通过当前键盘“移上屏”按钮的真实辅助功能点击动作，6 个下屏测试窗口全部迁移，包含 X11 普通/最大化/全屏/最小化/附属对话框和 Wayland 普通窗口，首轮回读在约 0.49 秒确认完成。GTK 客户端读取的最大化、全屏、最小化状态前后一致；原有上屏对照窗口、双屏桌面、任务栏、键盘和视频桥的位置与尺寸一致，所有窗口桌面与活动归属一致。测试窗口随后全部关闭。实机截图确认快捷栏九个按钮完整可见，下屏键盘与收起后的 Panel 均铺满；KWin PID 1420、Plasma PID 1566 保持不变，新键盘 PID 24751 无重启循环。

触摸快捷栏沿用“桌面”“终端”等按钮的输入路径，不使用手柄硬件输入门禁。键盘服务的私有用户命名空间只映射 UID 1000，不能以宿主机 root UID 校验该硬件门禁目录；该检查仍保留在原有硬件事件入口。

设备事务备份为 `~/.local/state/pocketds-linux-kit/<private-voice-transactions>/keyboard-window-transfer-b4061a1`；只变更键盘主程序和 adapter 内容，语音服务配置不参与事务。详细验收回执在 `~/.cache/keyboard-window-transfer-b4061a1/result.json`，并已复制到维护工作区 `outputs/keyboard-window-transfer-20260907/live-final/`。
