弹窗外观收敛为三个可复用组件：PanelDialog 管理标题、遮罩、关闭及焦点；DialogFooter 管理分隔线和动作排列；DialogButton 管理普通/主要/危险/忙碌/不可用外观。各页面仍保留自己的内容和控制条件。后续调整公共样式不需要逐个复制粘贴。

Qt Dialog 的内容间距与 header/footer 独立，公共组件分别设置这些边界；焦点和关闭策略沿用原生 Popup 机制，Android 的忙碌守卫继续使用原条件。参考 [Qt Dialog](https://doc.qt.io/qt-6/qml-qtquick-controls-dialog.html)、[Qt Popup](https://doc.qt.io/qt-6/qml-qtquick-controls-popup.html)。

## 边界

原生渲染运行于设备的隔离预览环境，外部执行、真实键盘输入、录音和硬件调整均被禁用。正常画面采用一次状态快照，其余为明确构造的场景。Qt 点击/Escape 测试是隔离窗口内的原生事件，不代表物理触控和手柄进出游戏的完整实机验收。

本文件记录设计阶段；其后已部署，实体按键页也已按用户新要求改为手柄测试。见 [部署记录](2026-09-06-panel-controller-deployment.md)。55 个场景是设计阶段覆盖的代表状态，不等于穷举所有数据组合。恢复异常页仍有收紧留白与去重说明的空间；这版不宣称为最终或最优设计。
