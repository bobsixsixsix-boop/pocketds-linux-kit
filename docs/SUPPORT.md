# 当前支持与已知限制

当前提供源码预览，安装目标是**已有匹配支持包的 AYANEO Pocket DS、Fedora 44/aarch64、
KDE Plasma Wayland**。`pocketds` 账户、下屏布局、定制内核和硬件接口都是当前基线的一部分。
尚未验证普通 Fedora、其他桌面、其他用户名或其他 AYANEO 机型；名称相似不代表硬件兼容。

## 验证范围

| 范围 | 已有证据 | 尚未覆盖 |
|---|---|---|
| 双屏、触摸、Panel | 维护者实机使用、开合盖恢复、正常重启后的显示与布局确认 | 其他设备、显示组合及长期恢复 |
| 键盘与触摸板 | 中文、终端和窗口转移；最新输入交接修复的离线回归、实机部署及用户确认 | 所有应用、全部多指时序和长期故障注入 |
| 手柄 | 实体按键对应、模式切换与游戏输入集成 | 全部外设、游戏及恢复组合；PDS-059 的虚拟鼠标释放补丁尚待部署和实机验收 |
| 语音与麦克风 | 历史私有后端的语音实测、蓝牙耳机录音改善；公开版已改为用户自备 API | 新 API 的真实服务调用与实机验收、不同耳机、声学质量与长时录音 |
| 合盖睡眠 | 匹配内核与 PowerDevil 修复下，真实 native 合盖睡眠、Hall 唤醒和双屏触摸恢复 | 长待机、全部充电/外设组合、另一台设备；完整闭盖 RTC 观察的尾段仍有限制 |
| 正常重启 | 后续正常重启已回到桌面，Fcitx Wayland 登录配置已验证 | 历史一次晚期关机停顿的根因仍未确定（PDS-056） |
| GPU | 已有负载与故障恢复调查 | 近期日用正常不能关闭历史 GPU/Mesa 问题（PDS-002） |
| 安装与分发 | 既有基线的组件更新；空素材、无授权、升级与回退的离线检查 | 另一台设备从头安装、完整通用卸载、签名镜像与独立救援 |

这里的实机记录来自维护者的一台设备。自动测试、一次人工确认和跨设备发行验收是不同层级
的证据；服务 `active`、屏幕状态字段正常或一张截图，也不能单独证明触摸、声音和物理显示正常。

## 首次源码预览的边界

- 不捆绑 ROM、BIOS、账号、访问码、个人壁纸、系统镜像或语音模型。
- 无语音授权或 Codex 登录时，普通键盘与基础 Panel 功能仍可使用；相关可选项显示未配置
  或不可用，不意味着已经完成对应服务的验收。
- 安装器更新覆盖层，仍会修改系统助手、授权规则及部分服务；具体见
  [安装、升级与撤回](INSTALL.md)。没有通用卸载器。
- 深度睡眠依赖匹配内核、补丁和实际运行的 PowerDevil 插件。检查拒绝时应查清不匹配项，
  不应通过删掉检查或绕过权限策略继续睡眠。
- 完整系统镜像、第三方运行时和设备支持包有各自的来源、许可与验证要求；公开源码不表示
  这些产物已随项目发布或保证可重新构建。
